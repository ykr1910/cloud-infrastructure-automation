# Cloud Infrastructure Automation & Three-Tier Application Deployment on Azure

## Overview

This project demonstrates the design, provisioning, deployment, and monitoring of cloud infrastructure on Microsoft Azure using Infrastructure as Code and DevOps practices.

The objective is to automate infrastructure provisioning, deploy a containerized three-tier application, and implement monitoring and CI/CD workflows.

## Technology Stack

- **Cloud:** Microsoft Azure
- **Infrastructure as Code:** Terraform
- **Containers:** Docker
- **CI/CD:** Azure DevOps / GitHub Actions
- **Operating System:** Ubuntu Linux
- **Scripting:** Bash, Python
- **Monitoring:** Azure Monitor
- **Version Control:** Git and GitHub

## Project Components

1. Azure infrastructure provisioning using Terraform.
2. Virtual Network, subnets, and Network Security Groups.
3. Three-tier application deployment.
4. Docker-based containerization.
5. CI/CD pipeline automation.
6. Infrastructure and application monitoring.
